# PBC 交资料（Obsidian 插件）

一句话：在手机或电脑上打开 PBC 清单页，点一下，选截图或文件，它会自动存好，并把图片放进对应那一行的「我的反馈」格子里。不用再在表格格子里手动插图片。

## 安装（iPhone / iPad / Mac 都一样，用 BRAT）

BRAT 是一个专门用来安装「测试版插件」的插件。

1. 打开 Obsidian，设置 → 第三方插件 → 关闭「安全模式」（如果还开着）。
2. 点「浏览」，搜索 **BRAT**（全名 Obsidian42 - BRAT），安装并启用。
3. 设置里找到 BRAT，点 **Add beta plugin**。
4. 填仓库名：`morgantina721-arch/pbc-attach`，版本选最新，点 Add Plugin。
5. 回到「第三方插件」列表，把 **PBC 交资料** 打开。

之后 BRAT 会自动检查更新。

## 设置

设置 → 第三方插件 → PBC 交资料：

- **PBC 文件夹**：默认 `财务/PBC`。只有这个文件夹里、名字像 `PBC-2026-11-24.md` 的页面才会生效。
- **附件文件夹**：默认 `财务/PBC/附件`，交的文件存这里，没有会自动建。

## 把命令加进手机工具栏（只要做一次）

1. 设置 → 工具栏（有的版本叫「编辑器」→「工具栏」）。
2. 在可选命令里找到 **PBC：交资料**，添加。
3. 之后在手机上打开 PBC 页进入编辑状态，键盘上方的工具栏里就有一个回形针按钮。

电脑和 iPad 上，左边竖条里也有一个回形针图标，点它效果一样。

## 怎么用

1. 打开 PBC 页，切到编辑状态（实时预览或源码都行，阅读视图下也能触发，但建议编辑状态）。
2. 想交哪一行，就把光标点进那一行（比如「A04 招行信用卡 未出账单截图」），再点回形针。
   - 光标不在任何编号行上时，会弹出一个列表让你选；还没交的排在前面，已交过的会标「已交过，可以再加」。
3. 弹出系统选择框：可以从相册多选图片，也可以从「文件」里选 Excel、CSV、zip、PDF。
4. 选完后，屏幕上会提示「已交到 A04：2 张图片、1 个文件」，那一行的「我的反馈」里就有了。

规则：

- 图片会改名成 `编号-日期-时间-序号`（北京时间），表格里显示缩小的预览。
- 其他文件（Excel、CSV 等）保持原文件名不变，因为后面处理时要靠文件名认出是哪家的。重名时会在后面加「 (2)」。
- 格子里原来写的字一字不动，新内容接在后面（用换行隔开）。
- 如果这一行在你操作期间被别处删掉了，文件还是会存好，只是不写进格子，提示里会告诉你存在哪。

## 常见问题

- 提示「当前不是 PBC 清单页」：确认文件在 PBC 文件夹里，名字以 `PBC-` 开头；或者去设置里改 PBC 文件夹。
- 同一个编号在页面里出现两次：只用第一处，并会提示。
- 手机选择框没弹出来：再点一次；如果是从列表里选行之后没弹，告诉我，需要换个方式。

## 开发（给懂代码的人）

```
npm install
npm test        # 纯函数测试（node:test）
npm run build   # 产出 main.js
```

发布：改 manifest.json 和 versions.json 的版本号，打同名 tag 推送，GitHub Actions 会自动建 release 并附上 main.js 和 manifest.json。
