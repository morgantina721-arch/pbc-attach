# PBC 交资料（Obsidian 插件）

一句话：在手机或电脑上打开 PBC 清单页，点一下，写几句话、选截图或文件，它会自动存好，并把话和图片放进对应那一行的「我的反馈」格子里。不用再在表格格子里手动插图片。

## 安装（iPhone / iPad / Mac 都一样，用 BRAT）

BRAT 是一个专门用来安装「测试版插件」的插件。

1. 打开 Obsidian，设置 → 第三方插件 → 关闭「安全模式」（如果还开着）。
2. 点「浏览」，搜索 **BRAT**（全名 Obsidian42 - BRAT），安装并启用。
3. 设置里找到 BRAT，点 **Add beta plugin**。
4. 填仓库名：`morgantina721-arch/pbc-attach`，版本选最新，点 Add Plugin。
5. 回到「第三方插件」列表，把 **PBC 交资料** 打开。

之后 BRAT 会自动检查更新。

## 设置

设置 → 第三方插件 → PBC 交资料：

- **PBC 文件夹**：默认 `财务/PBC`。这个文件夹**最上层**、名字以 `PBC-` 开头的页面才会生效（以「-细节」结尾的、放在子文件夹里的不算）。
- **附件文件夹**：默认 `财务/PBC/附件`，交的文件存这里，没有会自动建。

## 把命令加进手机工具栏（只要做一次）

1. 设置 → 工具栏（有的版本叫「编辑器」→「工具栏」）。
2. 在可选命令里找到 **PBC：交资料**，添加。
3. 之后在手机上打开 PBC 页进入编辑状态，键盘上方的工具栏里就有一个回形针按钮。

电脑和 iPad 上，左边竖条里也有一个回形针图标，点它效果一样。

## 怎么用

**光标**：打字时那根闪烁的竖线；点一下格子它就在那儿。

两种交法不冲突，随便用：

- 直接在表格格子里写字、插图，和以前一样。
- 用插件交：点回形针，弹出一个小窗，可以写话、选截图或文件。

步骤：

1. 打开正在用的 PBC 页（比如 `PBC-2026-11-23.md`、`PBC-补账-2026上半年.md`，只要在 PBC 文件夹最上层都行），切到编辑状态。
2. 想交哪一行，就把光标点进那一行（比如「A04 招行信用卡 未出账单截图」），再点回形针。光标在行上可以少点一步（直接弹小窗）；不在也没关系，会先弹一个列表让你选行，还没交的排在前面，交过的标「已交过，可以再加」。
3. 小窗标题是「交到：A04 …」。里面有一个输入框，想说什么写什么，可以不填。
   - 点 **选截图 / 文件**：弹出系统选择框，可以从相册多选图片，也可以从「文件」里选 Excel、CSV、zip、PDF。选完后，话和图片/文件一次写进格子，话在前、图片在后。选择框如果取消了，小窗还在，写的字不会丢。
   - 点 **只交这句话**：只写文字（输入框是空的时这个按钮点不了）。
   - 点 **取消**：什么都不写。
4. 屏幕上会提示「已交到 A04：…」。

### 「其他想说的」

如果页面里有一个以「## 其他想说的」开头的小节，列表最下面会多一项「其他想说的（随手写）」。选它，同样写话、选图片，内容会作为新的一段加在这个小节的最后（和上面空一行）。没有这个小节就不会出现这一项。

### 自己加的、没编号的行

你在「我的反馈」表里自己加的行（第一格是空的，或者没写 A01 这种编号），不会出现在列表里。想交到这一行：把光标点进这一行，再点回形针就行。如果这一行刚好被改过，会提示「这一行刚被改过，没写进去」，文件已经存好，不会丢。图片会命名成「补充-日期-时间-序号」。

### 规则

- 图片会改名成 `编号-日期-时间-序号`（北京时间），表格里显示缩小的预览。
- 其他文件（Excel、CSV 等）保持原文件名不变，因为后面处理时要靠文件名认出是哪家的。重名时会在后面加「 (2)」。
- 写进格子的话：换行会变成换行符 `<br>`，竖线 `|` 会自动转义，不会弄坏表格。
- 格子里原来写的字一字不动，新内容接在后面（用换行隔开）。
- 如果这一行在你操作期间被别处删掉了，文件还是会存好，只是不写进格子，提示里会告诉你存在哪，写的话也会显示出来。

## 常见问题

- 提示「这页不用交东西」：确认打开的是 PBC 文件夹（默认 `财务/PBC`）最上层、名字以 `PBC-` 开头的页面。放在「归档」「细节」等子文件夹里的页面、名字以「-细节」结尾的页面，都不算。
- 同一个编号在页面里出现两次：只用第一处，并会提示。
- 手机选择框没弹出来：在弹出的小窗里再点一次「选截图 / 文件」；还是不行，告诉我。
